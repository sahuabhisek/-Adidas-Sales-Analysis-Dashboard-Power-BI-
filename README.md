# 👟 Adidas Sales Analysis Dashboard (Power BI)

An interactive Business Intelligence dashboard built to analyze Adidas retail sales performance, regional revenue distribution, product trends, and profitability metrics.

## 📌 Project Highlights
- **Total Revenue:** $899.90M
- **Total Profit:** $332.13M (42.30% Avg. Profit Margin)
- **Top Product Category:** Men's Street Footwear ($209M)
- **Top Retail Partner:** West Gear ($243M)

## 🛠️ Tools & Skills Demonstrated
- **Tool:** Power BI, Power Query, DAX
- **Data Modeling:** Star Schema / Relational Data Structuring
- **Visualizations:** Maps, Donut Charts, Area/Line Charts, Bar Charts, and KPI Cards
- **Interactivity:** Region and Year Slicers for dynamic cross-filtering
